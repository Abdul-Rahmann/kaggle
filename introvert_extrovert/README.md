# Predict the Introverts from the Extroverts

## **Overview**
Welcome to the 2025 Kaggle Playground Series! This challenge follows the tradition of providing interesting and approachable datasets for the Kaggle community to practice their machine learning skills. Each month, a new competition is introduced as part of the Playground Series.

### **Objective**
Predict whether a person is an **Introvert** or **Extrovert**, based on their social behavior and personality traits.

---

## **Evaluation**
Submissions are evaluated using the **Accuracy Score** between the predicted values and the observed target.

### **Submission File Format**
The submission file must contain the following:
- A header row.
- Two columns: `id` and `Personality`.

Example:
csv id,Personality 18524,Extrovert 18525,Introvert 18526,Introvert ...

## **About the Tabular Playground Series**
The goal of the Tabular Playground Series is to:
- Offer lightweight, synthetic datasets for fast experimentation and skill-building in machine learning.
- Provide opportunities to iterate through various model-building, feature engineering, and visualization ideas.
- Feature relatively short-duration challenges (lasting a few weeks).

### **Why Synthetic Datasets?**
Synthetic datasets are used to:
- Balance real-world data characteristics while keeping test labels private.
- Allow for more interesting datasets with fewer artifacts compared to earlier competitions.
- Offer datasets that are generated with advanced techniques to better mimic real-world data.

Your feedback on these datasets is greatly appreciated to improve future competitions!
